# Raffa

A static landing-page project built with HTML, CSS, and a Swiper image carousel.

## Preview locally

Clone the repository and open `index.html` in a web browser. No build step is required.

Alternatively, with Python 3 installed, run from the repository folder:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000. Internet access is needed for the Swiper JavaScript and stylesheet loaded from the CDN.

## Repository guide

| Path | Purpose |
| --- | --- |
| [index.html](index.html) | Layout, navigation, and carousel initialization |
| [Design/style.css](Design/style.css) | Styles |
| `Design/` | Images and font assets |

## Project scope

The page includes an automatically advancing image carousel, a hero section, and sample highlights. Navigation and sign-in links are placeholders; there is no authentication service or backend in this repository.

Company text and placeholder highlights are part of the demonstration page. Existing source and asset credits have been retained.
